Personal fitness tracker used for Push/Pull/Legs/Cardio exercise regime. Keeps track of strength and endurance progression of exercises, and automatically sets new benchmarks when old limits are surpassed.

- Gym session data needs to be recorded in standardized obsidian .md files in order to be parsed
- Created Shell Alias to use to run the program on terminal: `run-progression`
- Access application page via http://localhost:5173
